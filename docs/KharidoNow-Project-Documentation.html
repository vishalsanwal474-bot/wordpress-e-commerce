2. Project Overview

KharidoNow is a complete online clothing store inspired by the shopping experience of platforms like Amazon and Flipkart. It provides a light, simple, and responsive interface for customers, plus a secure admin panel for managing the catalog, orders, customers, reviews, and coupons.

The original request asked for a WordPress e-commerce site. Because PHP/WordPress/MySQL were not available on the development machine, the project was implemented as a Node.js + Express application that delivers the same functional flows (storefront + admin CRUD + order lifecycle) and can be extended into a real production store.

Brand: Site name is KharidoNow. Logo artwork is included in the header, footer, and admin login. Brand colors follow the logo palette: navy blue and vibrant green on a light UI.

3.4 Why these technologies

  • Runs without PHP, MySQL, Apache, or Docker on the current machine.
  • Fast to start for demos and college/project submissions.

  • Easy migration path later to PostgreSQL/MySQL and real payment gateways.

4. System Architecture

Browser (Customer / Admin)
        │
        ▼
 Express Server (server.js)  ← Port 3000
   ├── Session middleware (cart, auth, CSRF, flash)
   ├── Storefront routes (/shop, /cart, /checkout, …)
   ├── Admin routes (/admin/…)
   ├── EJS views (views/)
   ├── Static assets (public/)
   └── Data layer (lib/db.js → data/store.json)

Requests are rendered on the server (SSR). Cart and login state live in the session cookie. All catalog, order, and user changes are written back to data/store.json.

10. Data Model

Stored in data/store.json as collections:

  • users — id, name, email, phone, password (hash), role
  • addresses — linked to userId
  • categories — id, name, slug, image
  • products — sku, name, slug, brand, price, comparePrice, stock, sizes, colors, gender, categoryId, image, ratings, featured
  • orders — orderNo, items, totals, address, payment, status, timeline
  • reviews — productId, rating, comment, user
  • coupons — code, type (percent/flat), value, minOrder, active
  • wishlists — userId + productIds[]

On first run, lib/db.js seeds ~20 clothing products, categories, demo users, sample coupons, and one sample order.

11. Business Rules

  • Shipping: Free if (subtotal − discount) ≥ ₹499; otherwise ₹49.
  • Coupons: Applied only if active and minimum order is met.
  • Stock: Reduced on checkout; restored if customer cancels (Pending/Confirmed).
  • Payments: COD = Pending; demo UPI = Paid.
  • CSRF: All state-changing POST forms require a session CSRF token.
  • Auth guards: Customer routes need login; admin routes need role = admin.

12. UI / UX Design Notes

  • Light theme for easy shopping (not dark-mode heavy).
  • Primary navy #1e40af and accent green #16a34a from the logo.
  • Amazon/Flipkart-like patterns: top offer bar, sticky search header, category nav, filters sidebar, price summary, order timeline.
  • Mobile breakpoints collapse grids, show menu toggles, and stack product/admin layouts.

14. Testing Checklist

  1. Home loads with logo and categories.
  2. Search “shirt” shows suggestions and shop results.
  3. Open a product → choose size/color → Add to cart.
  4. Apply coupon WELCOME10 or FLAT200.
  5. Checkout with COD → order confirmation + tracking timeline.
  6. Customer cancels a Pending order.
  7. Admin login → edit product, change order status to Shipped/Delivered.
  8. Resize browser to mobile width → nav and grids remain usable.

15. Going Live (Production Path)

This project can become a real working website. Recommended next steps:

  1. Deploy Node host (Render, Railway, VPS, etc.) + custom domain + HTTPS.
  2. Replace JSON storage with PostgreSQL or MySQL.
  3. Integrate Razorpay / PayU / Stripe for real payments.
  4. Add email/SMS order notifications.
  5. Move secrets to environment variables; rotate admin password.
  6. Add privacy policy, refund policy, and GST/invoice support as required.

WordPress alternative: If a hosting plan with PHP + MySQL is available, the same business flows can be rebuilt using WordPress + WooCommerce. This Node project remains a complete functional reference/prototype.
